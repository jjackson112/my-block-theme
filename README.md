# Dorothy de Long – Custom WordPress Block Theme
This project is a custom WordPress Full Site Editing (FSE) block theme developed and tested in a local Docker-based WordPress environment
The theme leverages modern WordPress features such as `theme.json`, block-based templates, and template parts, and is intended for learning, experimentation, and portfolio demonstration.
- HTML (WordPress theme development)
- Tailwind CSS
- JavaScript
- Custom archive templates
- Responsive mobile navigation
